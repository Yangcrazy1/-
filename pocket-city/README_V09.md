# 小星球 · 自由之城 V0.9 手机 H5 试玩

本轮按用户要求只交付试玩、调试与测试版本。没有制作或提交小红书平台上传包。保留 V0.8 的出租车、风格化跑车、坦克、直升机、战斗机、任务、电台和本地存档。

## 手机打开

下载 `pocket-city-v0.9-mobile.html`，用支持本地 HTML 和 WebGL 的浏览器打开。也可以下载 ZIP，解压后打开 `index.html`。文件完整包含脚本、模型、贴图和原创音乐合成，不需要 CDN、登录或服务器。

Android 的文件管理器、微信/小红书内置预览器可能只显示源码或不允许执行脚本；请选择外部浏览器。iPhone「文件」预览也可能不执行脚本，需要后续通过指定的 HTTPS 静态托管地址用 Safari 打开。本轮没有指定公网托管目的地，也没有获得实体手机，不能承诺所有手机直接文件打开成功或某个机型帧率。

点击「进入街区」。左摇杆走跑，拖场景转视角，右侧跳跃、攻击和上下车。「载具」卡片支持左右原生滑动。「地图」显示三片岛城及桥路，点沙滩、赌场、狮身人面像即可前往；需要先下车/下机。

## 新内容与修复

- 三片岛城的海岸、沙滩色带、分区局部街网和完整地图；保留球面道路连通、经度接缝和两极旅行。
- 自由城海湾沙滩、彩色遮阳伞、救生屋、棕榈、长椅和可走木栈桥。
- 圣安地列斯「绿洲赌场」外景，砂岩柱廊、金字塔屋顶、蓝绿玻璃；旁边是带蓝金头巾、狮身前爪和人面的原创雕像。赌场目前没有室内或赌博玩法。
- 水岸步行扫掠限制、汽车驶入水面回退、地标碰撞体和安全落点搜索；道路和码头可跨越水面。
- CJ 白色背心与宽松蓝色牛仔裤；Tommy 青绿棕榈印花衬衫、后梳黑发、宽下颌和金色腕表。保留 Quaternius CC0 的完整人体、65 根骨骼与走跑动作。
- 衣服分区沿几何接缝切分三角形，同时插值、归一化骨骼权重，修复原先整片三角形分类造成的破碎衣摆。修正新增头发和腕表的绑定空间。行人动作使用实际位移速度，减少受阻时的原地踏步。
- 角色菜单默认显示实际 WebGL 模型，海报仍可切换；奶油白、海玻璃绿与暖砂岩 UI/场景配色。

## 开发与验证

```bash
npm ci
npm run build
npm run check
npm test
python3 scripts-v8/dev-server.py --port 8090
python3 scripts-v9/browser-smoke.py
```

构建入口仍为 `scripts-v7/build.py`；`src-v9/` 是本轮地图、地标、人物细化和 UI；兼容生成 `game-v7.js`、`game-v8.js`、`game-v9.js` 和 `dist/index.html`，请编辑源文件而非生成文件。

70 项逻辑回归保留之前的 61 项并增加人车持续移动、配饰绑定、海岸、码头、地标到达/碰撞、服装权重和旅行限制。浏览器检查横竖屏、原生滑动、实际模型、三个景点、摇杆与阻断网络后的启动，报告位于 `reports/v09/`。云端 Chromium 使用 SwiftShader，不能代表真机 FPS；文件导航被云浏览器策略阻止时，报告会明确记录并改用内存中的同一 HTML 验证断网启动。
