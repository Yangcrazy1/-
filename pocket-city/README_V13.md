## 人物修复

V0.12 服装采用反复裁切三角面的网格。其静态肩部的边计数没有发现开口，因此不能把用户截图中的全部破面都归因为静态拓扑洞；独立裁切、权重量化、硬法线、背面轮廓与自阴影也可能放大变形裂痕。

本版恢复 CC0 原始连续人体拓扑，统一重合接缝的骨骼权重与法线，将服装分区／纹样放在绑定空间 Shader 中处理，不再切分肩部三角形。移除英雄的背面膨胀描边和自接收阴影，保留投影。身体从约 8.3–8.4 万个顶点降至每人 7,601 个顶点，11,802 个三角形（含原网格中合并的鞋面／鞋底）；不是重做成简化胶囊人。

CJ 保持白背心、宽松蓝裤、短发；Tommy 重塑下颌／鼻部、收细眉形，采用重新雕形、连贯的后梳发际线，青蓝棕榈短袖与开领／门襟；麦克保留西装和成熟造型。三个角色用同一身体与 65 骨骼贯穿动作；鞋子仍在同一身体网格。八套原始动作和星球不同位置的接地／连续性检查保留。

软件渲染保留同一个身体和独立的皮肤／上衣／裤子材质分区，不依赖 Shader；颜色与细节为简化路径。

三城连通球面、正常街景远景投影、行人和车流、任务、警察、抢车、武器、电台、坦克、直升机、战斗机、旧存档、星球总览均继续保留。世界半径仍为 104 米，本轮不扩大地图。一天为 300 活动秒，08:00 开始，菜单／后台／总览暂停。

## 两个交付格式

- 手机试玩：`outlaw-liberty-city-v0.13-mobile.html`。全部资源内嵌，小于 10,000,000 字节；无需 ZIP。长按 HTTPS 链接下载，用支持本地 HTML / JavaScript / WebGL 的外部浏览器打开。文件管理器预览或 iPhone 文件预览可能不执行脚本，真机本地打开未验证。
- 小红书小工具：`outlaw-liberty-city-v0.13-xhs-minitool.zip`。针对创作服务平台「小工具」的离线 ZIP 入口，不是普通笔记附件，也不是小程序原生小游戏工程。前往 `https://creator.xiaohongshu.com/new/red-app`，将 ZIP 原样上传，无需解压。平台账号、类目与审核以后台实际提示为准。

平台版使用外置经典脚本、包内资源、ES2017 / Chrome 61 语法与旧 CSS 回退；不依赖 CDN、eval、内联 JS 或网络。原生 Storage 的版本检测／错误反馈和串行保存保持旧存档字段。平台限制不允许音频文件选择，故保留六套内置合成电台；单 HTML 仍保留本机歌曲导入。平台容器不支持 requestFullscreen，按钮提示旋转手机。无 SDK 的浏览器可用兼容存档；现代 SDK 读失败时保留临时进度并明确提示，避免覆盖未读出的旧档。

小红书文档的直接访问受云网络策略限制，格式依据公开同步的官方 1.6.0 资料和已核查的 MIT 社区实现；精确版本与链接见平台目录。已做本地格式、严格 CSP、SDK 模拟检查，不代表实际小红书 iOS / Android 容器或审核通过。

## 运行、源码和配置

```bash
npm ci --cache /tmp/liberty-v13-npm-cache
npm run build
npm run check
npm test
python3 scripts-v8/dev-server.py --port 8097
python3 scripts-v13/browser-smoke.py
python3 scripts-v13/visual.py
python3 scripts-v13/acceptance.py
```

编辑 `src-v13/characters.js`、`src-v13/architecture.js` 与必要兼容钩子，构建仍为 `scripts-v7/build.py`，不要改生成 `game-v*.js`。

- 建筑／人物美术：`src-v13/`；可复用几何／材质缓存保留。
- 水面、材质、信控时长：`src-v10/config.json`。
- 地图半径／密度：`src-v11/config.json`。
- 小红书适配源码、构建与测试：`platform/xhs-minitool/`。
- 可复核证据：`verification-v13.json`、`reports/v13/`、`reports/xhs-v013/`、`ACCEPTANCE_V13.md`。

本轮真人体、美术、交通、碰撞、旧玩法回归在云端完成。性能目标为中档安卓稳定 30 FPS，云端 SwiftShader 不能证明手机达到目标。没有实体手机与小红书容器，不声明可上线终极成品或审核通过；人物与建筑细节仍与商业参考有差距。
