# 侠盗自由城 V0.11 — 人物修复与紧凑街区

基于当前 V0.10 工作树继续开发，基线提交 `2f5a4e6bd2f9d360886771cce7802ab2b02c3040`。用户确认采用 V0.9 人物观感，同时要求缩小地图、缩短楼间距、丰富空地与远景。本轮不从旧 ZIP 覆盖工程。

## 本轮改动

- 以 V0.9 的人体、发型和宽松牛仔裤为基础，移除 V0.10 的二次腿部收细及衣物位移。三人仍使用同一套完整的 65 骨骼身体贯穿动作。
- 重做 CJ 的连续 U 形背心领口、Tommy 的花衬衫 V 形开领与门襟、麦克的西装胸前细节。删除悬空的硬质领片／胸牌，服装图案直接随身体蒙皮变形。手掌恢复皮肤材质；鞋子使用绑定到脚骨的圆润鞋面和鞋底，合并在原身体网格中，遮去原来的赤脚轮廓。
- 修正脚踝到鞋底的距离，移除按相位突然启停的接地校正，改为有界且连续的骨骼修正。原始动作先进行短时平滑；路缘视觉高度平滑，跳跃仍由物理控制。
- 慢渲染帧的动画仅推进实际执行的物理时间，避免人物原地快速踏步。步行镜头加入候选机位迟滞，减少遮挡边缘频繁切换机位。
- 球面半径从 154 米调整到 116 米，线性距离缩小约 24.7%，面积缩小约 43.3%。人物、道路、车辆和建筑仍保持米制尺寸；水面 Shader、海底、碰撞和导航使用同一个新半径。
- 352 栋建筑分布在三城，使用实际矩形检查地块，沿街连续排布并填充后院地块。近邻间距中位数约 1.70 / 1.56 / 1.78 米；单位球面面积的建筑密度比 V0.10 提高约 7%。新增 21 处街角休憩点、垃圾桶／花箱／路牌，三处海湾远景礁岸与树木轮廓；天空增加轻量云层及浅青色地平线。
- 保留三城连通、交通、行人、信控路口、任务、武器、抢车、警察、电台、汽车／坦克／直升机／战斗机、昼夜、存档和星球总览。

## 运行和测试

```bash
npm ci
npm run build
npm run check
npm test
python3 scripts-v8/dev-server.py --port 8094
python3 scripts-v11/browser-smoke.py
python3 scripts-v11/acceptance.py
python3 scripts-v11/visual.py
python3 scripts-v11/endurance.py
```

主要源码在 `src-v11/`，兼容钩子在 `src-v7/` 至 `src-v10/`。构建入口仍为 `scripts-v7/build.py`。不要编辑生成的 `game-v*.js`。`src-v11/config.json` 控制半径、建筑排布、接地平滑和镜头迟滞；水色／交通配置沿用 `src-v10/config.json`。

`npm test` 运行 89 项，包括全部 81 项原有回归。球面尺寸与停放飞机检查改成与当前半径对应的米制断言；原建筑中心距大于 5 米的断言按用户要求改成实际矩形不重叠且间隙大于 0.18 米。原两极闭合、碰撞、任务与战斗断言继续保留。

图片在 `reports/v11/`。角色有正／侧／背三视图。街道前后截图使用相同快速前往目的地和游戏镜头规则；由于地图缩小，并非相同的绝对世界相机矩阵。波浪像素测试在当前版本的固定机位独立执行。测试接口不包含在交付 HTML 中。

## 手机文件与小红书

手机交付为 `outlaw-liberty-city-v0.11-mobile.html`，全部资源内嵌，约 3 MB，无需解压。下载后使用允许本地 JavaScript／WebGL 的浏览器打开。真实手机文件打开与安卓 30 FPS 未在实体设备验证。

用户新增小红书上传需求。本工程使用 DOM／WebGL／Web Audio，是 H5 游戏。小红书的 H5 小工具入口与小程序／小游戏开发者工具不能互换；正在等待用户提供上传入口或文档，以确定文件格式、项目配置、平台适配层及身份字段。`platform/h5-candidate/` 只提供已改名的 H5 静态入口和明确的格式状态，不冒充已适配／已审核的平台工程。
