# 小星球 · 自由之城 V0.8

本轮交付是可离线运行的手机 H5 开发版本。`dist/index.html` 是完整单文件，图片、模型、脚本与音乐合成都已包含，不需要 CDN 或登录。

## 手机试玩

1. 下载 HTML，用允许执行 JavaScript、支持 WebGL 的浏览器打开；Android 可使用支持本地 HTML 的浏览器。
2. iPhone「文件」或聊天软件中的文件预览可能不执行脚本。遇到这种情况，需要通过静态网站托管后的 HTTPS 页面在 Safari 打开；本次没有指定托管域名，因此没有发布公网网址。
3. 点击「进入街区」。左摇杆移动，推满奔跑；右侧跳跃、上下车和攻击；拖动场景转动视角。横竖屏均可使用。
4. 打开「载具」，左右滑动卡片，点击呼叫，再走近上车。坦克需要较宽空地；战斗机先垂直升空再切巡航。

文件能下载、构建和离线渲染，并不代表所有手机的文件预览器能运行 HTML。本轮没有拿到 Android/iPhone 实机，不能承诺某个机型的 FPS。

## 本轮改动

- 缓存重复招牌，共享静态城市纹理图集，合批建筑、车辆不透明材质；小物件使用较低细分，保留完整球面与三城、任务、交通、飞行和存档。
- 缓存路人旧版武器壳，避免每名路人重复构造随后丢弃的人体；每种路人服装保留独立颜色，身体仍是带权重的完整人物网格。
- 三位主角继续使用同一完整骨骼基础，分别微调肩胸、头部和下颌轮廓；保留服装、发型与配饰差异。这是对现有 CC0 模型的调整，并非三套新雕刻的写实人物。
- 持械步行不再选用全身站立动作。腿部继续走跑，上半身叠加握持姿态；同步走跑循环相位，清理完成淡出的动作；近处人物不再统一按 16 Hz 更新。
- 动作混合从固定物理子步中收集，在渲染帧更新一次。运动碰撞仍保持有上限的 60 Hz 扫掠步进。
- 行人也会避开停放车辆，缓存车辆碰撞体减少重复计算，并修复近处交通造成的人物重叠。
- 碰撞考虑人体完整高度；可以从雨棚下方行走，跳起时会碰到雨棚。新增重叠修复，增大角色行走安全间距。
- 行走镜头使用多个安全候选位和带厚度的遮挡检查，车辆使用简化的镜头碰撞体。
- 暖纸色、墨蓝与陶红 UI；可滑动的图示载具卡片；新增履带坦克、炮塔与发射动作，保留出租车、两种法拉利风格跑车、直升机、战斗机及其他汽车。
- 修复菜单根节点、按钮与纵向 flex 排列阻止滑动的问题，菜单可以纵向滚动，载具可以原生触摸横滑，鼠标也可拖动。
- 新增加载页，在引擎求值和构建世界前先显示，包含真实阶段进度和错误提示；没有用虚假的定时器填满进度条。

## 开发

已有 Node.js 24、Python 3.12。游戏运行、构建不需要 npm，完整测试需要安装锁定的测试依赖。

```bash
cd /workspace/-/pocket-city
npm ci
npm run build
npm run check
npm test
```

`src-v8/` 存放本轮的性能、物理/镜头、载具/UI、加载页模块。继续使用 `scripts-v7/build.py` 作为兼容构建入口，产出 `game-v7.js`、`game-v8.js` 和 `dist/index.html`。不要直接编辑这些生成文件。

本地调试：`python3 -m http.server 8090 --bind 127.0.0.1 --directory dist`。浏览器回归：`python3 scripts-v8/browser-smoke.py`，需要环境预装的 Playwright Python 和 Chromium。报告位于 `reports/v08/`。已有云任务具有隔离环境，使用现有 checkout，不要另建 Git worktree。

## 验证与发布范围

61 项逻辑回归覆盖旧有玩法与新动作、碰撞、坦克行为。浏览器验证使用真实 Three.js WebGL 路径，但 GPU 为云端 SwiftShader；横竖屏、原生触摸滑动、呼叫坦克、摇杆移动和无网络资源渲染分别记录。具体数据以 `reports/v08/` 当前报告为准。

目前按用户选择交付 H5。没有绑定小红书平台身份、上传审核或发布公网站点。上架前还需具体平台 SDK/包体要求、真机性能和兼容性验收，以及现有角色名称、品牌和美术的商业发行确认；本版没有包含从 GTA 提取的模型或商业歌曲。
