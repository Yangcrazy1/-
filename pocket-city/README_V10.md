# 小星球 · 自由之城 V0.10 — 清新海湾试玩

本轮使用当前 V0.9 工作区继续开发，未解压旧工程覆盖修改。参考项目／会话 ID：`01a16708-2512-71fc-94bc-1e85de06a0a9`。性能档位采用用户选择的中档安卓优先；本次仍交付离线 H5 试玩，平台上传留待后续要求。

## 手机下载与打开

从本仓库 `downloads/` 下载英文文件名 `pocket-city-v0.10-mobile.zip`，解压后用支持本地 JavaScript 和 WebGL 的浏览器打开 `index.html`；也提供独立的 `pocket-city-v0.10-mobile.html`。不要用聊天软件的文本预览打开。

下载使用 GitHub HTTPS 实体文件，不再使用聊天内指向云工作目录的失效附件链接。发布后会从 HTTPS 链接取回文件并核对 SHA-256。手机具体浏览器的本地文件支持仍需实际设备确认，iPhone 文件预览可能需要改为部署到指定 HTTPS 网站后在 Safari 运行。

## 本轮可玩内容

- 约 95 米海风大道和约 89 米木栈步道，连接原有完整球面道路；三城、任务、交通、武器、电台、抢车、警察、直升机、战斗机、存档和星球总览继续保留。
- 球面浅岸、近海和深海层次，两层方向／频率／速度不同的约 2–6 厘米微波浪，位移与法线同步；三维采样连续跨经度接缝。岸沫推进、碎光、掠射天空近似和昼夜水色；没有新增反射 Pass。
- 干沙、湿沙、缓坡海底、局部沙丘、半米网格的海湾细岸。浅水脚步涟漪、车辆小水花、直升机近水悬停扰动和限量脚印；池化回收。桥面在水上抬高，并以岸边缓坡过渡，避免波峰穿桥。
- 木板实体厚度和板缝、柔和木纹、礁石群、贝壳、漂流木、海草式低植被、乔木与灌木、花盆、观海长椅、低围栏、救生设施和海风咖啡摊。植被共享几何、实例化颜色和轻风动画。
- 海滨大道、住宅街、商业背街、行人木栈步道四类道路，补充连接路、T 字巷、斑马线、停止线、停车位、车道箭头、减速标记、井盖、排水沟和桥墩。木栈道禁止汽车驶入。
- 六处受控路口，使用同一个活动世界时钟；绿／黄／全红／行人放行／清空期配置化。AI 车辆提前限速制动并保持停止线余量，绿灯平滑起步；行人与车共享保护状态，过街未清空时车灯保持红灯。玩家仍可自由驾驶，不会被强制按红灯锁死。
- 建筑增加实体窗框、窗台、木雨棚、花箱与屋顶设备；三城继续保留不同的住宅、海湾度假和都市组合。
- 三位主角保持身份及同一身体网格／65 骨骼；调整脸型、鼻眉、头发、腿部体型、宽松花衬衫、口袋、鞋底及服装肩线。动作过渡约 0.18 秒；使用实际速度匹配步频，增加停步／落地重心、球面接地和脚部校正、同骨架驾驶姿态及部分长枪支撑手校正。近战有约 0.105 秒准备，再执行原有接触伤害和收势。
- 紧凑单行任务卡、压缩时钟／金钱／警星，步行／驾驶／飞行独立按钮网格。关键按钮至少 48 CSS 像素；升降、下机、巡航模式和速度／离地距离分开。保留摇杆、点击、长按和双击操作。
- 每次开始 08:00，约 300 活动秒一天；菜单、轮盘、后台与总览暂停太阳时钟。角色切换和模型预览主动释放独有骨骼纹理、几何与材质，保留共享资源。

## 构建、配置与验证

```bash
npm ci
npm run build
npm run check
npm test
python3 scripts-v8/dev-server.py --port 8092
python3 scripts-v10/browser-smoke.py
python3 scripts-v10/acceptance.py
python3 scripts-v10/endurance.py
```

构建入口仍为 `scripts-v7/build.py`；本轮主要源代码在 `src-v10/`，必要钩子在原模块中。生成的 `game-v7.js`、`game-v8.js`、`game-v9.js`、`game-v10.js` 是同一当前版本的兼容别名，不应直接编辑。`src-v10/config.json` 配置材质色板、水波／特效上限、交通时长和性能目标，构建时嵌入 HTML，无运行时下载。

`verify-v10.cjs` 在原 70 项玩法回归上增加 11 项检查。原地面半径检查已改为校验解析海底／地形高度，仍核对完整两极与闭合球面；原近战检查等待准备时间后核对相同伤害，未删除旧玩法断言。DOM 测试画布补全真实尺寸。

浏览器证据位于 `reports/v10/`：同机位前后、真实水面像素变化、浅水交互和池回收、20 次车辆通行、9 组驾驶／飞行布局、三指操作／取消、弹层防穿透、昼夜与总览、模型预览资源回收和断网启动。QA 注入接口仅存在于测试脚本，不包含在交付 HTML。

持续运行脚本使用真实墙钟时间测试 3 分钟步行、3 分钟驾驶、2 分钟直升机及 2 分钟战斗机，并记录平均 FPS、P95 渲染帧间隔、绘制次数、三角形、几何／纹理和 JS 堆趋势。结果以实际生成的 endurance.json 为准；云端 SwiftShader 和共享 CPU 不代表安卓 GPU、发热或真机帧率。

本版是可继续开发的 H5 测试包。完整验收状态和限制见 `ACCEPTANCE_V10.md` 与 `PROJECT_STATUS.md`；没有执行小红书上传审核。

配置生效范围：交通相位时长、制动余量、路口数量，水波幅度、水深权限、交互池容量、三档水色和水网格分段直接读取 JSON。环境木材／墙面还有源代码中的手绘配色变化；人物／距离预算部分沿用兼容核心。修改波频或人物预算时，应同步检查对应 Shader／兼容核心与 CPU 采样，不能仅凭配置字段认为所有路径都已变化。
