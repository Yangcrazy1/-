# 侠盗自由城 V0.12 — 紧凑街景与木庭院

从当前 V0.11 工作树继续开发，基线 `fb978f9ba3cc80e6b66b51e7aea68e032bd229bd`，分支 `codex/cozy-dense-v012`。用户反馈旧版地图仍显空旷、远处楼间断开。本轮保留角色和全部玩法，按参考图中的自然木材、庭院植物、柔和色彩调整环境。

## 可感知的改动

- 球面半径 116 → 104 米，线性距离减少约 10.3%，总面积减少约 19.6%。人物、车辆与房屋保持米制尺寸。道路宽度收为 4.8–5.9 米，步道保留独立宽度。
- 三城共 320 栋建筑，实际矩形非重叠校验；近邻近似净间距中位数 1.32 / 1.25 / 1.42 米，上一版为 1.70 / 1.56 / 1.78 米。建筑数量随地图面积减少，单位面积密度较 V0.11 增加约 13%。
- 过去小球面的地平线过近，缩小半径反而会让房屋更早沉到视线下。本版将正常街景映射到角色附近的连续局部平面；95 米内完整映射，95–155 米平滑过渡。物理、导航、角色坐标仍然是球面，星球总览保持真实球体。
- 点地移动、目标屏幕位置、镜头障碍与街景使用相同映射。用 `atan` 而不是近原点精度较差的 `acos` 计算局部角度，避免角色附近小偏移被量化。内嵌 Shader 对实际 WebGL 编译验证。
- 远处的详细建筑批次退出后，以一个实例绘制保留窗格立面。静态批次改用投影后的包围体裁剪，避免把整个城市都强制绘制。
- 增加 约 15–16 处木庭院地板、围栏和盆栽，木底商、雨棚，以及 约 51–52 组庭院／岸边树和 153–156 丛灌木。重复树冠与树干采用共享实例；Canvas 回退将实例烘焙为普通网格。
- 出生点和三城快速前往改为优先选择有连续建筑的安全街边，初始出租车移到附近可停放的位置。正常角色、行人、车流保留。
- 路面使用低对比颜色，减少重复斑马线；横屏工具按钮移动到下方，为前方街景留出空间，按钮热区仍至少 48 CSS 像素。
- 修正海岸边界处“当前点不满足通行条件便绕过岸线检查”的问题。不能再从该分支直接穿过深水。

## 源码、配置、运行

```bash
npm ci
npm run build
npm run check
npm test
python3 scripts-v8/dev-server.py --port 8096
python3 scripts-v12/browser-smoke.py
python3 scripts-v12/acceptance.py
python3 scripts-v12/visual.py
python3 scripts-v12/endurance.py
python3 scripts-v12/package.py
```

- `src-v12/presentation.js`：连续街景、屏幕拾取、镜头代理、裁剪。
- `src-v12/streetscape.js`：远景、木庭院、树丛、落点、软件回退。
- `src-v12/interface.css`：本轮 UI 调整。
- `src-v11/config.json`：当前 V0.12 半径、沿街建筑参数；保留原路径便于兼容构建。
- `src-v10/config.json`：材质、水面、交通时长和粒子上限。
- 构建入口仍为 `scripts-v7/build.py`；`game-v*.js` 和 `dist/index.html` 是生成文件。

保留三位主角、同一归一化身体／骨架，以及三城连通、驾驶／抢车、警察、任务、武器、电台、坦克、直升机、战斗机、存档、300 秒昼夜和总览。没有从旧压缩包替换当前工作树。

## 交付与边界

手机试玩为 `outlaw-liberty-city-v0.12-mobile.html`，约 3.02 MB，资源全部内嵌，无需解压或联网。正式交付使用仓库 `downloads/` 中经过 HTTPS 字节校验的文件。GitHub 原始文件通常以 text/plain 返回；手机可长按下载链接，下载后用支持本地 JavaScript / WebGL 的浏览器打开。

`npm test` 包含全部 89 项旧回归与 6 项本轮检查。上一版尺寸／版本断言按当前地图更新，路缘测试寻找当前路网中的实际路缘；屏幕测试坐标更新为实际显示投影；原有碰撞、归一化权重、三城人口、交通、任务与战斗断言继续保留。

浏览器证据在 `reports/v12/`。`*-fixed-camera.png` 使用同一路段索引与相同相机局部偏移／焦距；地图缩小后并非同一绝对世界矩阵。其他三城图显示各版本实际快速前往落点。图片是实际渲染，没有修饰。

测试环境为 Linux Chromium WebGL / SwiftShader。十分钟运行的帧率、P95、绘制调用、三角形和资源变化须与最终 HTML 哈希对应；这些不能证明实体安卓稳定 30 FPS。软件回退保留原球面视野，视觉效果较 WebGL 简化。参考图是美术方向，当前程序化资源仍有风格和细节差距。
