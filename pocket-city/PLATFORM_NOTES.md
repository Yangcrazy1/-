# 手机与后续小游戏适配

本轮平台目标是离线 H5。低依赖、资源内嵌、池化特效、共享几何／材质、距离裁剪、用户手势启用音频、安全区和 48 CSS 像素触控为后续小游戏适配保留基础。

当前 UI 使用 DOM、Canvas、Web Audio、本地文件选择和 localStorage；它不是可直接提交的小红书／微信小游戏 SDK 工程。后续指定平台后，应替换输入／音频／存储／资源加载适配层，接入平台生命周期、分包与审核要求，再在平台真机中测量性能。不要通过修改 ZIP 后缀声称完成平台适配。

材质和交通配置在 `src-v10/config.json`，由构建脚本内嵌；无需运行时 CDN。资源许可保持原 Three.js MIT、Quaternius CC0 及本工程原创程序资源。
