## 已知问题和未验证项

- 无实体安卓／iPhone，没有证明中档安卓稳定 30 FPS、温升或真实触控手感。SwiftShader 会明显低于手机 GPU，不应据其数字宣传达标。
- 本地文件导航在云 Chromium 被策略拦截时，使用同一 HTML 的内存断网启动；实体手机文件管理器／浏览器直接打开待验证。GitHub 下载也受用户网络可达性影响。
- 没有真实小红书 Android / iOS 容器、后台账号、上传或审核；本地严格 CSP 和原生 SDK 模拟不能代表平台已通过。官方文档域名无法直接访问，来源版本与边界见平台 SOURCES.md。
- ES2017 可解析和 CSS 回退不等于已经在真实旧版 Chrome 61 / iOS JSCore 跑过。WebGL 软件回退使用更简单的色彩／材质和原球面街景。
- 轻量人物没有全套新的高模拓扑／动作捕捉；接地和武器握持仍沿用轻量校正。极端姿态、相机近裁切、复杂屋顶、碰撞挤压、长时间混合拥堵待设备游玩复核。正常镜头和本轮动作测试肩部稳定，与商业参考仍有精细度差距。
- 三城连续球面、紧凑地图未扩大；场景远景映射只用于正常 WebGL 街景，物理和总览仍为真实球面。海水为天空近似，无 SSR / 额外反射。
- 赌场保持外观地标。平台版移除本机歌曲导入／全屏调用，保留内置电台；手机 HTML 保留原功能。没有借本轮增加真实赌博、账号或数据收集。
