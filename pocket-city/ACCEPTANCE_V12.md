# V0.12 验收与已知问题

本轮目标是缩小地图、压缩楼间空白并改善参考图中的生活环境。以 `PROJECT_STATUS.md` 和 `reports/v12/SUMMARY.md` 的最终冻结记录为准。

| 项目 | 证据 |
| --- | --- |
| 地图缩小，三城和道路连续 | `src-v11/config.json`、`verification-v12.json`，含经度接缝／两极／全路网连接回归 |
| 密集楼间距、无重叠 | `reports/v12/city.json`；原实际矩形重叠与最小分隔断言保留 |
| 远景建筑持续存在 | 实例远景测试、同路段相机截图、三城实际视角截图 |
| 木庭院、盆栽、树丛 | `reports/v12/density.json` 及海湾／街道截图 |
| 角色服装和动作保留 | 同一身体、65 骨骼、权重和脚踝连续性回归；浏览器角色预览资源回收检查 |
| 屏幕拾取和镜头同步 | 新增逆投影误差测试、投影后的镜头障碍射线测试 |
| 水面、浅水交互、粒子回收 | `acceptance.json` 的波浪像素变化、足／车／旋翼事件及回收 |
| 红绿灯、人车运动 | 20 次红停绿起、20 次行人清空逻辑测试；实际浏览器人车坐标变化 |
| 横竖屏与多点触控 | 9 种驾驶／飞行布局、三指取消、弹层穿透、载具原生滑动 |
| 离线、大小、资源依赖 | 单 HTML 小于 10,000,000 字节；浏览器离线启动，零联网请求 |
| 十分钟运行 | `endurance.json`；必须满足实际连续时间 ≥600 秒并匹配交付哈希 |
| 下载可靠性 | 仓库 `downloads/` 中 HTTPS 响应／字节／SHA-256 校验记录 |

已知限制：

- 没有实体安卓手机，30 FPS、发热、不同手机文件管理器能否直接执行 HTML 未验证。
- 云端 SwiftShader 为软件 GPU，其帧率不能当作手机性能结论；首次进入模式仍会建立资源缓存。
- 正常街景采用局部显示投影，95–155 米为过渡区。点地目标限于清楚可见的近景地面（约 94 米），远距离可用地图或摇杆前往。
- Canvas 无 WebGL 回退仍保持球面地平线；水、叶片和光照效果简化。
- 当前采用程序化房屋、植被和原有角色；与参考图的手绘美术完成度仍有差距。
- 小红书上传包尚不能被称为适配完成：实际上传入口和 SDK 要求未提供。
