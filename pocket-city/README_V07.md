# 小星球 · 自由之城 V0.7

可离线运行的手机网页单人 Alpha，以及可交给 Codex 继续修改的源工程。

## 开始试玩

打开 `dist/index.html`。运行不需要联网，不需要安装依赖。手机应选择支持 WebGL 的浏览器打开；部分系统文件预览器不会执行游戏脚本。也可以把 `dist/` 放到静态网站服务上运行。

手机左摇杆：轻推走路、推到底快跑；点击地面走路，长按快跑，双击跳跃 / 翻矮墙。拖动画面调整镜头，点行人或车辆锁定，右侧攻击、上下车和跳跃。开车时前推油门、后拉制动 / 倒车，左右转向。直升机与垂直起降战斗机有升降按钮。

右侧三个米色小卡片依次是电台、服装配色、物品。物品面板可直接装备八种武器；原有武器和电台轮盘仍可使用。设置中的「切换时段」可快速体验白天、夕阳、夜晚与晨曦。

## 这一版交付的变化

- 完整的人体拓扑和 65 根骨骼；主角有 7,281 个身体顶点，保留鼻子、耳朵、下颌、手掌、手指与鞋的体积。站、走、跑、跳、持枪与近战使用同一个身体网格，平滑混合动画。
- CJ：白背心、深肤色、短发、银链和手臂图案；Tommy：蓝色花短袖、衣领、纽扣、金链和侧分头；麦克：深色西装、浅色衬衣、翻领和灰色鬓角。三个配色方案可在游戏中切换。它们是卡通化演绎，并非 GTA 官方模型。
- 使用实际游戏服装纹样，选人页保留三张独立漫画海报。人体与动作基于 Quaternius 的 CC0 资源，见 `ASSET_MANIFEST.md`。
- 修复快速旅行后空街：三个城区都有预置人车，并补充玩家附近的安全街道人流。测试中第二城区到达后近处有 24 名行人、11 辆车；往返六次均正常。保留全局 288 名行人、125 辆汽车、11 名步行警察和 6 辆警车。
- 三城建筑保持不同轮廓与材料，增加低、中、高层的差异。全世界共 1,514 栋建筑，21 条连通道路、135 个路口，完整球面没有地图围墙。星球半径 154 米，表面积约 0.298 平方公里。
- 每次点击开始均为 08:00。完整游戏日为 300 秒：白天、夕阳、夜晚、晨曦；夜间有窗灯与霓虹。菜单、轮盘、星球总览及后台暂停计时。
- 自动画质按实际每帧工作开销调节，优先减少远处人物和阴影的负担；避免因后台 RAF 限速不断降低清晰度。画布不会降至一个 CSS 像素以下，WebGL 启用抗锯齿。
- 路人身体使用从同一完整人体表面简化的 2,142 顶点 / 4,358 三角面网格；主角保持完整网格。保留静态街区合批、距离裁剪、AI 分频更新、空间网格碰撞与有限粒子池。

V0.6 已有的车辆驾驶、抢车、出租车接送、竞速、直升机投递、战斗机飞行、法拉利风格跑车、八种武器、火箭炸车、通缉、非血腥击倒反馈、小地图、星球总览、电台和存档均保留。

## 开发与构建

`src-v7/characters.js`、`world.js`、`interface.js` 和 `interface.css` 是本次更新的可编辑模块。`src-v7/runtime-v6-checkpoint.js` 与 HTML checkpoint 是旧版兼容核心；构建时重命名最后一个同名实现，再接入新模块。不要直接修改自动生成的 `game-v7.js` 或 `dist/index.html`。

构建只需 Python 3：

```bash
python3 scripts-v7/build.py
node --check game-v7.js
```

完整逻辑回归需要 Node.js 和 `@napi-rs/canvas`：

```bash
npm install
npm test
```

游戏运行与构建都不依赖 npm。测试报告为 `verification-v7.json` 和 `verification-v7-run.log`。`scripts-v7/prepare-assets.py` 是可选的美术资源再加工脚本，使用 NumPy/Pillow，原始动画包不包含在压缩工程中；正常构建直接使用已加工的 `assets/rig-v7.json`，因此仍可完全离线。

## 验证范围与下一步

本版是可玩 Alpha。逻辑回归与手机横竖屏浏览器交互已检查；当前云端浏览器禁用 WebGL，画面核查使用 Canvas 软件回退，不能据此宣称真实 Android / iPhone 达到 30 或 60 FPS。实际手机 GPU 画质、发热、内存、长时间驾驶和平台适配仍须真机验收。

仍需后续美术：更有个人辨识度的脸部雕刻、手持武器的逐帧握持校正、更完整的女性和不同体型 NPC、服装层的专门网格。当前保留统一基础人体以兼顾体积与动作一致性，不宣称达到 GTA 原作或成熟商业游戏的成品水平。

继续开发的具体清单与已授权要求见 `CODEX_HANDOFF.md`。工程未绑定外部仓库或游戏平台，也未执行上线发布。
